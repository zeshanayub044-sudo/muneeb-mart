# The MUNEEB MART Journal

The Journal is the native WordPress posts archive at `/journal/`, inside the same installation as WooCommerce. Eight original demonstration articles and ten editable categories are included. Original watch photography illustrates styles and does not verify a product specification.

## Publish and edit

1. Sign into `/wp-admin/` and open Posts → Add New. Enter the title, write with normal WordPress blocks, and use H2 and H3 for sections.
2. Set a category, optional tags, an excerpt and a featured image with useful alt text. For custom uploaded images, WordPress uses your Media Library settings. The imported articles have tailored editorial alt text.
3. Open **MUNEEB MART · Search appearance** below the editor. Save an optional SEO title and meta description. These fields also support pages and products. Search engines may choose different snippets.
4. Save a draft, preview, or publish. Use WordPress’s date controls to schedule an article. Local scheduling relies on WordPress page visits; a public host must permit and successfully run the relevant scheduled event before timing can be guaranteed.
5. Set the author through WordPress’s author control. Assign real editorial identities through Users, without inventing credentials or experience.

Published posts automatically enter the Journal archive and the homepage’s three latest articles. Category and tag archives, search restricted to posts, pagination and article navigation use WordPress’s native queries. Changing a post to draft removes it from public lists. The importer checks each slug and preserves existing posts rather than replacing edits.

## Article presentation

The theme supplies category/author/date, estimated reading time at 220 words per minute, featured image, contents links for articles with at least four sections, sharing links, related articles and recommended WooCommerce products. Product recommendations on the eight imported articles use the saved collection list. New articles work without that optional metadata; use product/collection links or the native WooCommerce product blocks in the editor.

The main menu and footer link to the Journal. The global watch-search dialog links to the Journal search. Blog categories are managed in Posts → Categories, while product collections are managed separately in Products → Categories.

## Search and indexing

The theme outputs the article’s canonical URL, Open Graph metadata and BlogPosting structured data, plus normal WordPress feeds. Built-in WordPress XML sitemaps become available at `/wp-sitemap.xml` when search visibility is enabled. The current demonstration store deliberately uses noindex. Before indexing, replace fictional products, approve business/policy details, confirm public HTTPS and mail, then turn off demo mode and change Settings → Reading → Search engine visibility.

No analytics, Search Console or Bing account is connected. No search rankings or indexing results are promised. If a full SEO plugin is later used, the theme defers its head metadata when Yoast or Rank Math is active; migrate the optional custom fields into that plugin as needed.

## Editorial standards

The eight articles contain approximately 1,060–1,150 words each and reference official manufacturer documentation for technical care/movement facts. Advice is general, and a particular model’s manual takes priority. No hands-on testing, customer testimonial, material, water resistance or movement claim is made about the fictional catalog. Recheck external sources and model instructions when updating technical advice.
