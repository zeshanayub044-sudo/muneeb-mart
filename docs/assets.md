# Asset provenance

All watch photography was generated specifically for MUNEEB MART on 29 October 2026 using the available image generation tool. Prompts requested original, unbranded watch designs without dial text, trademarks or watermarks. The four generated originals depict a dark steel hero, a steel product, a rose-tone product, and a leather watch on warm sandstone. Source PNGs/JPEGs are retained locally under ignored `assets-source/`.

The theme ships optimized WebP copies: `hero.webp`, `steel.webp`, `rose.webp`, `editorial.webp` and `leather.webp` (the latter two use the same original). Demo products share these illustrative images; they are not evidence of actual material or movement specifications. WordPress creates responsive attachment thumbnails when the demo importer runs. Product alt text identifies demonstration imagery.

Typography uses local system serif/sans fallbacks (Georgia / Times New Roman and Inter if installed, otherwise Arial). No remote font tracking or font downloads are required. Icons are inline SVG paths defined in the theme. No third-party watch-brand photography, logos, fabricated reviews, or ratings are included.
